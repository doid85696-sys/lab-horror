# Horror Lab (Fabric 1.21.1)

Хоррор-лаборатория: двери с карточками, противогаз, пистолет, мутанты, ядовитый газ.

## Игра
- `/horrorlab build` (нужны права оператора) — построить лабораторию рядом с вами; вход спереди (на юге).
- Стартовый сундук: пистолет, патроны, противогаз (надеть в слот шлема), аптечки.
- Карточки уровней 1–3 лежат в сундуках; дверь открывается, если карточка нужного уровня в руке.
- Газ травит всех без противогаза. Мутанты не открывают двери. На «Мирном» режиме мобы пропадают.

## Сборка
Локально: `gradle build` (Java 21, Gradle 8.8+) → `build/libs/`. Для wrapper: `gradle wrapper`.
GitHub: `.github/workflows/build.yml` собирает jar на каждый push и кладёт его в Artifacts.

Текстуры и ассеты генерируются `python3 tools/generate_assets.py` (плейсхолдеры — замените своими).
